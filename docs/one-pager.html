Self-hosted workflow automation for the Verkada API.

Catch every webhook, mirror the audit log, put Gemini on your cameras, and write the answers back into Command as Helix events. Think Zapier, built around Verkada. One Docker command, your hardware, your keys.

Beta · built by a Verkada SE · not an official Verkada product
1 · See
Everything that happens
Webhooks classified and HMAC-verified. The Command audit log, mirrored every 10 seconds and filterable by user, event, device, IP, key, endpoint and status. Who streamed which camera, for how long.
→
2 · Automate
Flows on a canvas
Start on a webhook, a schedule, or any audit-log entry. Analyze a clip, a frame or the audio with Gemini. Branch on the answer. Unlock a door, fire a lockdown, call any endpoint.
→
3 · Land in Command
Helix events, Command alerts
Results post as searchable Helix events on the camera and timestamp. Command's own notification rules take it from there. No new app for operators to watch.
🔎
Audit log, uncapped
Verkada's page stops at 90 days and a handful of filters. vFusion keeps the history you choose, counts every value before you click, exports CSV, and turns any entry into a trigger.
🧠
Draft a flow from a sentence
"When anyone streams the nursery camera, log who to Helix." Grounded in your real cameras, doors and events, validated, and replayed against history so "will this fire?" has evidence.
🎥
Gemini on your cameras
Historical clip, a single live frame (≈10× cheaper), or just the audio track (≈8× cheaper). Species, OCR, shelf stock, obstructions, camera health: eight templates ship ready.
🧪
Workbench
Try a prompt once against a camera or an upload before building anything. Run any Verkada endpoint with pickers for the ids. Watch cameras live in the browser.
🏷
Helix, end to end
Draft event types from a description, send test events, read back what is really on Verkada, and seed a week of realistic demo data for an integration that isn't built yet.
🎬
Virtual camera
Serve your own clips, a URL or a live stream to a Command Connector over RTSP with ONVIF Profile S, on one unbroken stream. Generate footage with Veo that looks like a dome shot it.
📡
MQTT object positions
Broker, certificates and credentials generated for you. Cameras publish live bounding boxes; watch them, filter the false positives, replay any track beside its footage.
🧰
MCP explorer
Browse Verkada's Model Context Protocol server with the key you already have. Every tool badged read-only, writes or destructive, and a history of when each appeared.

Built for the system it talks to

  • Two-factor sign-in, throttled login, secrets encrypted at rest, keys generated on first boot.
  • One public path. Only POST /hooks/verkada ever faces the internet; the dashboard stays on your LAN or VPN.
  • Is anyone else using my key? A monitor flags any address using your Verkada key that isn't vFusion.
  • Cost tracking and a spending cap for everything that spends. No telemetry, nothing phones home.
  • Least privilege by design: scope the API key to exactly what your flows need.
